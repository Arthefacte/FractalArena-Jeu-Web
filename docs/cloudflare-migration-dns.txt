; POURQUOI CE FICHIER : le scan automatique de Cloudflare rate régulièrement

;     les en-têtes de sécurité et HTTPS forcé
;   - les 5 MX et le TXT       -> DNS only (nuage GRIS) : un MX proxifié casse
;     la remise du courrier
